Math derived from the real code (src/lib/nextSpinOdds.ts, header comment): rollTriggerCents draws the hidden trigger T uniformly on the integers [seed, ceiling]; applyProgressiveSpin adds the tier contribution c first and hits when meter + c >= T; c = floor(bet × bps / 10,000) plus 1 cent with the dropped-fraction probability (splitContributionUnbiased), so E[c] = r × b exactly. Because the meter only rises and every bet adds at least 1 cent per tier, a meter V above seed means T is uniform on (V, C]: P = E[min(c, C−V)]/(C−V), which equals r·b/(C−V) whenever c ≤ C−V and is capped at 1. At a fresh reseed (V = seed, nothing checked yet) T can equal the seed, so P = E[min(c+1, C−S+1)]/(C−S+1) (≈ (r·b+1)/(C−S+1)). Grand: randInt(mysteryCoinInPerHitCents) < bet, so P = bet / 31,500,000 exactly (1 in 35,000 at $9), independent of the meter. Ratios are exact integers; display only rounds down: ≥10% whole percent floored, 1–10% one decimal floored, below 1% "1 in N" with N rounded up; "100%" only when the spin certainly reaches the ceiling.
